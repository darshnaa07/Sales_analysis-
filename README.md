# Sales Analysis Project

## Project Overview

This project analyzes a fictional sales dataset containing 30 sales transactions.

The data was organized and analyzed using Google Sheets to understand overall sales performance, salesperson performance, and basic sales metrics.

## Dataset

The dataset contains the following information:

- Order ID
- Date
- Product
- Category
- Quantity
- Price
- Salesperson
- City
- Total Sales

All data used in this project is fictional and created for learning and portfolio purposes.

## Analysis Performed

The project includes:

- Total sales calculation
- Total number of orders
- Total quantity sold
- Average order value
- Highest and lowest sales
- Sales by salesperson
- Basic sales visualization

## Key Results

| Metric | Result |
|---|---:|
| Total Sales | ₹8,35,300 |

## Key Insights

- Rahul generated the highest total sales.
- The total revenue from all 30 orders was ₹8,35,300.
- The average order value was approximately ₹27,843.
- The highest individual sale was ₹1,38,000.
- The lowest individual sale was ₹3,400.
- Sales were generated across Delhi, Mumbai, Noida, Lucknow, and Kanpur.
